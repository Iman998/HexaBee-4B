# Data and model distribution

The software license covers this repository's code and accompanying documentation. It does not license upstream datasets, hosted services, model weights, or the underlying Wikipedia articles.

The release contains hand-authored demonstration records, illustrative prompt seeds, rubric/template code from the authors' construction workflow, numeric evaluation artifacts, and an extracted numeric training trace. It does not bundle the original Wikipedia-derived corpus, synthetic corpus, raw benchmark texts, private model outputs, model weights, or service credentials. The paired-score table releases content hashes and numeric scores rather than text.

Gemma and other model assets remain subject to their respective distribution terms. Dataset and checkpoint publication requires separate provenance and attribution appropriate to those assets. Numeric paper results describe the archived experiment; rerunning a generation service with the same public alias can produce different content.

All drawing geometry is generated locally by the provided plotting scripts. No Flaticon assets or company logos are redistributed.
