# راهنمای فارسی

این مخزن کد مقالهٔ **HexaBee-4B** را در ماژول‌های مستقل ارائه می‌کند: ساخت دادهٔ سؤال‌وجواب چندزبانه، ساخت و ترکیب سیستم‌پرامپت، تولید دادهٔ ترجمه، تنظیم آموزش لورا، ارزیابی ترجمه و تولید جدول‌ها و شکل‌های مقاله.

ایدهٔ بخش سؤال‌وجواب این است که سؤال به زبان مبدأ داده شود و سیستم‌پرامپت زبان پاسخ را مشخص کند؛ خروجی باید **پاسخ سؤال** باشد. در بخش ترجمه، ورودی و خروجی متن‌های هم‌تراز به دو زبان‌اند. هدف اصلی ارزیابی مقاله ترجمه است. آزمایش حذف مؤلفهٔ سؤال‌وجواب موجود نیست و کد یا مستندات، سهم مستقل این مؤلفه در بهبود را قطعی معرفی نمی‌کند.

از ریشهٔ مخزن، دستورهای بخش Quick start در README را اجرا کنید. این مثال کوچک به GPU یا API نیاز ندارد. فایل‌های `examples/` نمایشی هستند؛ نتایج واقعی مقاله در `results/paper/` قرار دارند.

برای دادهٔ خودتان، مسیر فایل Wikipedia را به `pct4b normalize-wiki --input ...` بدهید، سپس از `qa-build` و `export-sft` استفاده کنید. فایل اصلی با پسوند `.json` نیز پشتیبانی می‌شود، حتی اگر محتوای آن JSONL باشد. می‌توانید ابتدا `--limit 100` بگذارید. مستندات [داده](data.md) قالب ستون‌ها، دادهٔ چندزبانه، پرامپت‌ها و بازسازی تاریخی را توضیح می‌دهد.

برای بازسازی جدول‌ها، مقایسهٔ تمام جهت‌های ترجمه و شکل‌ها:

```bash
python scripts/reproduce_paper.py --plots
python scripts/build_paper_figures.py
```

خروجی‌های تازه در `runs/paper/` و `figures/` ساخته می‌شوند. جداول شامل بهترین مقدار به صورت بولد، مقدار دوم زیرخط‌دار، رنگ اختصاصی مدل و مقایسهٔ جاج با مرجع و بدون مرجع در هر هشت بُعد هستند.

دستورهای تولید با API در حالت پیش‌فرض فقط پیش‌نمایش تنظیمات می‌دهند؛ برای اجرای واقعی باید endpoint و کلید را در متغیرهای محیطی تنظیم و `--execute` اضافه کنید. پاسخ‌های معتبر در SQLite کش می‌شوند تا اجرای قطع‌شده قابل ادامه باشد. کلیدها، وزن مدل، دادهٔ اصلی و کش API داخل بستهٔ انتشار قرار نمی‌گیرند.

[راهنمای آموزش](training.md) ادامهٔ لورای مرحلهٔ اول در مرحلهٔ چندزبانه، مرج میانی، لورای تازهٔ ترجمه و مرج نهایی را توضیح می‌دهد. [راهنمای ارزیابی](evaluation.md) پارامترهای BLEU، chrF، chrF++، TER، COMET و bootstrap را دارد. [مرزهای بازتولید](reproducibility.md) مشخص می‌کند کدام نتایج از فایل‌های همین مخزن و کدام مراحل با داده، checkpoint یا سرویس اصلی بازتولید می‌شوند.


## انتشار در هاگینگ فیس

مدل نهایی، مدل میانی، سه لورا، داده‌های سه مرحله، مخزن پرامپت‌ها، خروجی مدل‌ها و نتایج ارزیابی در ۱۱ مخزن مستقل قرار می‌گیرند. [راهنمای کامل انتشار](huggingface.md) شامل نگاشت مخزن‌ها، بارگذاری آداپتور روی پایهٔ صحیح و دستورات آماده‌سازی، کنترل و آپلود قابل‌ادامه است. دستور `upload` به‌صورت پیش‌فرض فقط پیش‌نمایش می‌دهد؛ انتشار با `--execute` انجام می‌شود. توکن در فایل پیکربندی یا گیت ذخیره نمی‌شود.
